# Tossface

The files in this directory are the original Tossface web font distribution,
copied byte-for-byte from https://github.com/toss/tossface (`dist/tossface.css`,
`dist/TossFaceFontMac-00.woff2` ... `-11.woff2`) and the repository `LICENSE`.
They are not modified, subset, or converted. The `.woff` fallbacks referenced by
`tossface.css` are not bundled; every current browser loads the `.woff2` files.
